# Посмотри в окно

Проектная работа третьего спринта Яндекс Практикума. Приложение позволяет искать видеоролики по городу и времени суток, выбирать видео из списка и загружать дополнительные карточки.

## Технологии

- HTML и CSS, Flexbox.
- Кастомные чекбоксы с псевдоэлементами.
- Состояния наведения, нажатия и клавиатурного фокуса.
- JavaScript и API видеороликов из стартового проекта.

## Запуск

Откройте `index.html` в браузере или запустите проект через локальный HTTP-сервер. Для получения видео необходимо подключение к интернету и доступность API Практикума.

## Загрузка данных

Данные поступают из `https://v-content.practicum-team.ru/api/videos`. Если сервер недоступен, приложение завершает ожидание запроса через 15 секунд и показывает сообщение об ошибке. После восстановления соединения поиск можно повторить кнопкой «Найти».

При ошибке загрузки самого ролика отображается отдельное сообщение; другие карточки остаются доступны для выбора.
